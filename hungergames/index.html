Minecraft Classical Hunger Games Server

MC-HG is a project to bring the classic Hunger Games server gamemode back to Minecraft Multiplayer (not the Survival Games that arose after it and that we have today). You can join the Discord Server by contacting me via e-mail, although it it mostly dead by now

I have singlehandedly developed this plugin by myself, though it is outdated by some versions. It is currently functional with most essential features.
